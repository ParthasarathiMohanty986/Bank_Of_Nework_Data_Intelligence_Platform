# Technical specification

Python reads the four named CSVs with the standard csv library. Each ingestion command receives one folder, with four base filenames or four consistently dated filenames. SQLite stores the physical model and serves the single-host capstone deployment. All source timestamps are India local time. Merchant end dates are inclusive, and a blank end date is open. Store monetary amounts as integer paise.

Bronze stores row payload, file type, row number, and batch ID. A digest identifies a batch for replay protection. Silver has merchant history (one row per merchant and effective start), payment attempts (one row per transaction ID), settlement facts (one row per settlement ID), and payment events (one row per event ID). Constraints and indexes protect the fact grain and references. Customer ID is retained in the source payload only. Gold has one row per successful transaction; reporting queries aggregate this table by day and merchant. Rebuild Gold only for affected transactions. Merchant history additions may change previously unmatched rows, and orphan settlements/events are retried when their parent arrives.

Reject invalid fields, unsupported currencies and negative settlement amounts. Quarantine missing references, conflicting IDs and overlapping merchant history. Ignore identical business records and record duplicate events as warnings. Warn for event delivery lag beyond 30 minutes (an operational assumption separate from settlement SLA) and excess settlement. Order lifecycle events by event timestamp and ID. Store source row lineage on findings. Settlement timestamps earlier than payment timestamps are invalid. A pending settlement may transition to a terminal state under the same ID and transaction. No settlement is a business exception.

FastAPI serves settlement-summary and merchant-exceptions plus daily-trend, merchant-gaps and payment-exceptions under /api/v1. Dates are ISO calendar dates and inclusive. Invalid calendar dates or reversed bounds return 400, unknown merchant 404, missing or invalid parameters 422. The HTML dashboard calls same-origin JSON endpoints. Endpoints use parameterized SQL and require an operations bearer token set through the environment. Tokens and customer fields are excluded from API responses and application logs. Production requires TLS, restricted network ingress, database file permissions and managed secrets.

Monitor batch duration, rows loaded, rejections, quarantine, warnings and the last successful load. Health probes check database schema availability. Commit ingestion and affected Gold updates atomically. Deploy the same scanned container to DEV, TEST, and PROD with environment-specific secrets and database volumes.
