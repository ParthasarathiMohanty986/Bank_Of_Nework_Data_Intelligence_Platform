# Deployment and engineering review

GitLab runs unit, data model and API tests, then Bandit static analysis and pip-audit dependency scanning before building and pushing an image tagged by commit. The build needs a runner that supports Docker-in-Docker. Promote the same reviewed image digest through DEV, TEST, and PROD. Each environment has its own SQLite volume, input mount, access token, and network permissions.

1. DEV uses the base and incremental CSVs. Run the image with the data volume and a read-only CSV mount, overriding its command with python -m settlement.ingest /input. Start the app with the same data volume.
2. TEST verifies authentication, dashboard filters, smoke requests to /health and the summary endpoint, and unchanged totals after incremental replay. Verify that failed ingestion leaves the previous report available.
3. PROD mounts the same environment's persistent data volume into both the ingestion command and app. The container UID 10001 needs write access to that volume for ingestion and SQLite WAL files. Supply SETTLEMENT_API_TOKEN through the deployment secret manager, restrict app traffic to a TLS reverse proxy, and rotate tokens as needed. Use synthetic data outside production. A shared bearer token provides one operations role. An organization rollout can replace it with SSO for individual access and auditing.

Record ingestion CLI output centrally with restricted access. Alert on failed runs, stale ingestion, or changes in finding rates. Use /health for readiness. Archive delivered batches securely and take a consistent SQLite backup with the SQLite backup API before database changes. Roll back a bad application release by redeploying the prior image digest. For a database rollback, stop ingestion, restore the tested backup, restart the previous image, and replay verified batches delivered after the backup. Keep Bronze and its customer identifiers outside web-accessible storage. The capstone uses a single host and SQLite volume. Reassess storage and identity for multi-host production.
